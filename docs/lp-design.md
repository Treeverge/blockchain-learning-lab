# LP 流动性实验

日期：2026-10-12。用户已同意实施，沿用当前学习实验室的视觉与发布方式。

目标：解释提供流动性如何获得资产份额，以及手续费存在时为什么退出价值仍可能低于直接持有。四阶段为投入、交易、价格与套利、退出比较。

使用 6 位精度整数和原有恒定乘积报价。初始 LP 已投入各 1000 个资产；新用户钱包各 1000，按相同比例投入，自选 1 至 1000 个。新份额按贡献占原储备的比例计算，退出按当前储备与份额比例取回资产。网页版省略最小锁定份额，初始 LP 不退出，池子不会清空。

外部市场以 B 为计价资产，参考价格为每个 A 对应多少 B，可选择 0.5、1、2、4。价格本身不修改池子；套利账户实际在外部市场与池子之间交易，只有扣除池子费率后收益为正才执行。报价规模由连续模型的最优输入取整数候选，并检查实际整数收益，资金受套利账户现金及外部市场余额限制。省略 Gas、外部交易费、其他交易者竞争及预言机风险，不声称完整市场模拟。

对账范围包括钱包、池子、普通交易者、套利账户和外部市场。两种资产分别守恒。累计手续费是报价对应的留池流水，已经包含在池子储备与退出价值中，不另加到收益。

持有基准只针对本次投入的同批资产：投入 A × 当前外部价格 + 投入 B。LP 价值是可退出资产按同一外部价格计价，两者差值包含手续费、交易路径和舍入，不能一概称为纯无常损失。另显示无手续费、无额外交易的理想参考公式 2√r/(1+r)−1，明确假设。

退出后保存实际收到的资产并冻结情景操作，重置可开始新实验。失败不得扣款。整数模型、零费价格变为四倍约 −20% 的参考、双向套利、交易守恒、网页桌面/手机和减少动态效果均需验证。
