# 学习路径与自检工作台

目标：把八个独立网页串成能检验理解的中文学习路径。推荐顺序是哈希、签名/UTXO、节点、账户、交换、LP、借贷、安全，与原Day2/Day3目录顺序不同；原章节编号不变。用户可以自由跳转，不用强制解锁。

新增learning-path.html提供功能性的学习记录工作台；index.html仍是唯一项目入口和介绍。每站两道基于现有模型的情景题、一个书面解释提示、三个自检标准、一个可在源码副本或新增测试中完成的挑战。选择题按固定答案核对；解释没有关键词或AI评分，学习者对照标准自行确认。只有两题都正确且解释非空，才可确认“完成自检”；这不等于认证掌握。

复用lab.css的浅色背景、蓝色动作、等宽数字和边框。左侧是八站纵向导航，右侧为当前站点的实验入口、情景题、解释与源码挑战；手机改为上方纵向列表。无装饰卡片网格，无新字体或外部依赖。

curriculum.js是内容与进度规则的可测试UMD模块，learning-path.js只负责DOM、URL选择、存储及导出。进度版本1，键blockchain-lab.learning.v1，仅保存在当前浏览器源下。HTTP与file以及不同浏览器不保证共享。存储不可用或格式损坏时保留原数据、使用内存并显示提示；不因保存失败阻止学习。任何答案或解释修改会撤销该站自检标记。内容更新版本不静默迁移旧标记。

提供Markdown导出，包含解释、情景题选择及明确的自检标签；不用导入。清除当前站记录须用户确认，不提供隐式清空全局进度。文本通过textContent/textarea呈现，导出解释用Markdown引用格式，未知JSON字段及错误类型不可信。

八个实验页底部链接到对应站；首页补“按推荐路径学习”，说明路线、来源边界和书面输出。完成条件：进度与内容检查、存储失败/损坏/刷新、变更撤销、Markdown导出、跨页路由、全部站手机布局通过，独立复核、CI与Pages上线验证。
