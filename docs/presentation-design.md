# 分享材料校订设计

面向首次接触区块链、能阅读简单账本的中文学习者。分享目标是区分内容一致性、花费授权、共同历史与经济 / 合约风险，并能复现实验解释结果。保留 14 个 S 编号，讲稿与投影片逐页对应，40 分钟含三个现场实验；完整八站工作台作为课后路径。

## 内容与视觉

按用户最新要求，全站采用既有学习首页的纸白、深字、蓝色操作风格。演示文稿通过大字号和留白服务投影，不再保留深蓝金字皮肤。原演示仅替换文字会留下错误的 PBFT 投票与“二维码验证”交互，所以重新编排分享内容：本地中文系统字体、Consolas 数字、宽行距、左对齐大标题、横向流程与对账表。复用 lab.css 的颜色、字体、按钮与导航，遵循根目录 DESIGN.md 和现有实验路径，不引入字体服务、Canvas 粒子或网络依赖。14 页普通文档滚动，目录、上一页 / 下一页、键盘导航、深链接和打印可用；手机自然纵向排版。动画只强调当前页标题线，减少动态效果时关闭，脚本不可用仍能读全文。

顺序：封面、四层验证、三本账类比、协议差异、应用评估、工程录入边界、合约执行、TradeLens 历史反例、风险清单、采用决策、签名现场演示、PoW 分叉现场演示、DeFi 现场演示、八站学习路线与资料来源。不将多数票视为 PoW；不继续用旧 PBFT / RSA / 预设二维码动画作为主分享证据。三个旧独立演示也统一浅色样式、移除外部字体，并保留为未全面技术重写的历史资料，显示提示与新版入口。全站目前共 15 个 HTML 页面，均加载 lab.css。

Markdown 讲稿为单一内容源，以可重复的本地 Python 脚本生成 HTML 与 DOCX，避免三份文本漂移。DOCX 不含宏，HTML 不含脚本及远程资源。案例保留马士基 2022-11-29 原始公告并说明其关闭决定；技术引用 Bitcoin 开发指南、Ethereum 预言机文档、Solidity 0.8.20 安全说明。算例沿用已验证的网页模型；真实协议边界明确说明。

## 验收

浏览器检查 14 页目录、按钮 / 键盘 / URL 回退、交互焦点保护、所有本地链接、1440px / 390px、无脚本阅读、文件打开、打印和减少动态效果；视觉检查桌面与手机截图。生成文件校验与 Markdown 一致，DOCX XML 可解析且无宏。请求只读独立复核，修复后发布并确认同一提交的 CI 和 Pages。旧演示未全面技术重写，旧章节运行环境仍是后续工作。
