# 借贷与清算实验

日期：2026-10-12。用户已批准实施；沿用学习实验室布局、系统字体、蓝色操作与有限动效。

五步：存款提供资金；锁定抵押再借款；改变价格观察健康因子；补抵押或还款；清算并观察损失。使用虚拟抵押资产 C 和现金资产 B，均为 6 位精度整数。报价资产 B 是教学计价单位，不代表真实稳定币。

初始存款人有 10000 B，借款人有 4 C、0 B，清算者有 1000 B，池子为空。存款、锁定、借款、偿还与清算都实际转移账本资产。默认锁定 3 C、价格 100 B/C、借款 180 B。

借款上限为抵押价值的 2/3；清算阈值为 80%；健康因子 = 抵押价值 × 0.8 / 债务。是否可清算使用精确整数交叉乘法，严格低于 1 才可清算，显示健康因子向下取整到 6 位。价格范围为 10 至 200 B/C，价格变化不改变资产数量。

全额还款自动返还抵押并关闭情景。补抵押与部分还款可恢复健康；新增借款受累计债务、资金池和抵押上限约束。

清算使用与现有 Python 示例一致的“全额关闭或抵押不足后记录坏账”模型，奖励 5%，实际还款上限为抵押价值 / 1.05，向下取整。资金必须由清算者支付。抵押足够时返还剩余；不足时拿走全部抵押、未偿债务记录坏账。这是明确的教学选择，并不代表所有协议都使用全额清算或相同奖励。

现金与抵押分别对账；债务是债权，不是新增现金。显示存款债权、池子现金、未偿借款、已确认坏账；无利息模型满足现金 + 未偿债务 + 坏账 = 存款。贷款未清算时该等式不意味着可全额回收。清算或全额还款后冻结情景，重置可以重新比较。

省略利息、真实预言机、部分清算、存款退出、市场卖出、Gas 与其他风险机制；奖励依当前参考价计价，不等于已卖出获利。实验不使用钱包、不调用网络，直接双击也能运行。
