# 节点、分叉与账本重组实验

日期：2026-10-13。面向已经体验哈希与签名的中文学习者，将真实签名 / UTXO 与固定难度选链接起来。沿用共享字体、米白底色、蓝色操作、数字等宽字体和五步工作台；三个节点用于比较独立状态，窄屏纵向排列。

选择手动传播的三节点模型，便于核对收到交易、进入待确认池、被当前链确认的区别。自动传播动画会隐藏学习者要观察的先后顺序，真实 P2P 服务会增加部署负担；本轮采用手动模型。全部计算在一个浏览器中完成，支持 Pages 和本地文件。

五步：先传播交易；分别挖出两个分叉；比较等工作分叉；增加工作并重组账本；拒绝带有无权花费交易的更长候选。A / B 先收交易 X，C 先收冲突交易 Y；也允许自由选择节点与交易、改变确认顺序。

复用 UTXOLab 初始输出与临时 P-256 密钥。Alice 的同一笔 70 分别授权 X（Bob 45）与 Y（Eve 45），各费用 1、找零 24。初始余额 Alice 100、Bob 50、Eve 0；节点独立维护 chain、ledger、pending。两份交易初始均满足签名、所有权、未花费状态和金额检查。待确认池采用先接收的冲突候选，拒绝另一份是本实验的本地策略，不代表网络决定历史。

创世块的文本包含初始 UTXO / 费用 / 已消费 / 已确认状态的摘要，以其哈希作为共同锚点。后续每块放一笔交易或空块；data 为完整交易与 witnesses 固定数组编码的 SHA-256，绑定真实签名材料，避免主体 ID 相同却替换签名。区块哈希和 PoW 使用 ChainLab。难度固定为一位十六进制前导零，每个非创世有效块记 16 单位期望工作；不是本次实际尝试次数，也不是节点多数票。

候选必须先通过哈希、链接、创世锚点和证明检查，再核对交易摘要并从初始账本逐块执行 UTXO 校验。有任何无效交易，整条候选的有效累计工作为 0；即使证明工作更多也拒绝。完全相同的末块不重组，等工作保留当前链，更多有效工作才切换。

重组以共同祖先划分撤下 / 接入区块，采用新链完整重放的 ledger，替换旧费用而非累加。旧分支交易连同旧待确认池重新校验：新链已确认的跳过、仍有效且无池内冲突的恢复待确认、被新链花掉输入的丢弃并报告原因。默认 Y 分支增加一空块并传播后，A / B 从 Bob 95 / Eve 0 回到 Bob 50 / Eve 45；Alice 仍为 54、费用仍为 1，总量 150。X 仍有有效签名，但不能再次使用已消费的 70。

无效链挑战从共同创世开始，用 Eve 签 Alice 的 X 主体，再挖两个空块。三块真实证明通过，交易所有权不通过，不能替换两块的合法历史。挖矿可取消，每块上限 100000 次，最多 8 块；失败不提交节点的半成品。操作返回新网络快照，不修改输入。

边界：本地三节点快照，不是真实网络、Bitcoin 交易编码、难度调整、挖矿奖励、费用市场或安全钱包。空块没有费用或奖励。确认只是当前选中链的位置，未来有效更高工作分叉仍可能撤下它；不承诺绝对最终性。

验证覆盖：独立节点、待确认不扣款、冲突接收策略、真实挖矿、等工作不切换、更多工作回滚 / 重放、费用不重复记账、无效长链、签名材料承诺、孤立交易恢复、取消不提交；浏览器默认主线 / 自由传播 / 桌面 / 手机 / 展开长字段 / 文件打开 / 减少动态效果；上线后再验证。
