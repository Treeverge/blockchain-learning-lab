# 哈希、篡改与选链实验

日期：2026-10-12。沿用学习工作台和有限动效，用户已授权继续优化项目。

五步：查看哈希字段；篡改历史文本；重算后续链接；对比节点快照；加入工作量证明与选链。

使用浏览器 Web Crypto 的 SHA-256。固定序列化为 JSON 数组 [index, prevHash, data, nonce]，UTF-8 编码；nonce 是非负安全整数。保存哈希、自身重算哈希、前块链接和证明条件分别检查；前序失效时后块不代表整条链有效。

创世块哈希来自实验初始化的可信锚点，不从候选账本重新推导。要求区块顺序索引一致。工作量模式仅非创世块需要证明，所有节点共用外部设定的固定难度，候选链不能自报难度。难度是 1 至 3 位十六进制前导零；0 为无证明的教学阶段。

固定难度下累计工作使用非创世块数量 × 16^difficulty 的教学度量，等工作分叉保留当前链，更多有效工作才切换。与真实 Bitcoin 变动目标、精确 chainwork、传播、手续费、签名验证等不同。没有签名/余额的文本账本不能证明业务记录真实，也不能由此推出可以伪造真实转账。

三个节点只是本地快照。传播操作先验证候选；无效拒绝、等工作保持当前、更多有效工作接受。挖矿真实计算 SHA-256，异步分批让出页面，可停止，每块最多 100000 次尝试。停止或达到上限不提交半成品。更高难度增加期望工作而非保证本次耗时更长。

验证已知 SHA-256 向量、篡改与修复、创世锚点、索引、真实证明、等工作与更高工作、无效长链拒绝、停止不修改账本、桌面/手机、本地双击和公开页面。
