区块链学习实验室 · 使用说明
========================================

项目定位
以交互实验帮助中文学习者理解区块链机制，再通过源码验证结果。
学习方法：先预测 → 动手操作 → 观察账本 → 制造失败 → 解释原因。
项目入口统一为根目录 index.html。

快速开始
1. 双击 index.html，打开学习首页。
2. 从 DeFi 交换实验开始，观察报价、池子深度、手续费和报价变化。
3. 进入 04-六天实战源码/day5-defi，按 README.md 运行 Python 与 Solidity。
4. 如需技术分享，使用 02-演讲稿 与 03-演示文稿 中的原分享资料。

内容与状态
- 新版 DeFi 交换网页：本地计算、虚拟资产、无需钱包或服务器。
- Day 5 Python：整数交换报价、资金守恒、借贷累计债务与清算坏账。
- Day 5 Solidity：内部余额模型、最小接收量、比例投入与 LP 退出。
- 其他章节和原分享资料：保留原有内容，尚未完成本轮全面校订。
- LP 与借贷网页可视化：下一阶段扩展。

来源与许可
新增代码与文档使用根目录 LICENSE；上游代码与第三方素材见 THIRD_PARTY.md。
教学模型有明确简化，不代表完整协议实现。原分享案例应核对来源与时间。
