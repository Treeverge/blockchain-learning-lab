《区块链：从技术到信任》实战数字资料包 · 产品介绍与上架文案
================================================================

【一句话定位】
一场 40 分钟就能讲完、还带 3 个能动手玩的 Demo、外加 6 天手写源码的
区块链入门资料包。用石油、工程、供应链的真实行业场景讲区块链，听完
就能向别人讲明白，做完就能自己写一条链。

【你将获得（内容清单）】
1. 40 分钟演讲实录讲稿      Markdown + HTML    逐页口播稿，含翻页节奏与
                                                Demo 切换指引，可直接照着讲
2. 精美演示文稿             HTML（深蓝香槟金）  14 个 Section：定义、误区、
                                                场景、智能合约、落地案例、
                                                局限与决策框架
3. Demo ① 数字签名          交互式 HTML        生成密钥对 → 供应链签名链 →
                                                分布式验证 → 篡改检测
4. Demo ② 共识机制          交互式 HTML        拜占庭将军问题 → PBFT 三阶段
                                                投票 → 作恶节点拒绝 → 共识对比
5. Demo ③ 供应链溯源        交互式 HTML        咖啡豆全链路溯源 → 增/改/删
                                                三种篡改演练 → 油套管数字身份证
6. 六天手写源码             Python/JS/C#/Solidity  从零实现区块链、签名与
                                                 UTXO、智能合约、DeFi、安全攻防

【为什么值得买】
- 讲得透：三个关键词讲透区块链——数字签名（谁做的）、哈希链（没改过）、
  共识机制（大家都认），不讲玄学，全部落到代码和 Demo。
- 有行业味：全部案例取自石油工程、供应链、采油站——勘测、采购、焊接、
  压测、验收五阶段如何被区块链"锁死"，直接对接工业场景。
- 能动手：3 个 Demo 全部浏览器即开即用；6 天源码配套 README 与运行命令，
  Day1 到 Day6 循序渐进，从 JS 手写区块链一路到重入攻击防御。
- 能直接讲：讲稿是逐页口播级，含【↓翻页】【切到 Demo】等节奏标注，
  拿到就能做一场 40 分钟技术分享。
- 多语言多技术栈：Python、JavaScript、C#、Solidity 四栈覆盖，
  既有算法理解也有合约实战。

【适合人群】
- 想给团队/客户做区块链科普分享的工程师、产品经理、售前
- 需要为供应链、工程、工业场景设计溯源方案的从业者
- 想用一周时间动手理解区块链原理的学生与开发者

【学习路径建议】
3 小时快速通道（适合分享与认知）：演示文稿 → 三个 Demo 逐个玩 → 讲稿读一遍
6 天实战通道（适合动手）：按 Day1 → Day6 顺序跑代码，每章约 1–2 小时

Day 1   JS 手写区块链        区块、哈希、挖矿、矿池 9 个实验脚本
Day 2   Python/C#/JS 实现     可运行的完整链 + REST API + 测试
Day 3   签名 + UTXO + 脚本引擎 防伪模型与交易模型
Day 4   以太坊与智能合约       ERC-20 代币、存储模型（Remix 部署）
Day 5   DeFi 去中心化金融      AMM 做市、DEX、借贷清算、闪电贷
Day 6   工程实践与安全         重入攻击模拟与防御、工具链概览

【运行环境】
- 演示文稿与 Demo：任意现代浏览器，双击 HTML 即开（字体走 Google Fonts，
  可联网或自动回退）
- Python 部分：Python 3.8+，pip install -r requirements.txt（day2）
  或 pip install ecdsa（day3）
- Solidity 部分：Remix IDE（在线，免费）
